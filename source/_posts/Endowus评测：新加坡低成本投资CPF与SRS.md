Endowus 适合想用现金、CPF 普通户（OA）或 SRS 做长期基金投资，又不想自己选股的人。它提供基金组合和自动再平衡，最低起投 S$1,000。选择前重点看总费用、资金用途和赎回时间：**投资 CPF OA 并不保证能跑赢 2.5% 的基准利率**。

## 平台怎样管理资金？

Endowus 成立于 2017 年，受新加坡金管局（MAS）监管，以服务费为主要收费方式，不收基金销售佣金。基金管理人支付的销售回扣（trailer fee）100% 返还客户。

平台提供 250 多只互惠基金（Unit Trust），包括 PIMCO、Dimensional、Schroders 等机构的产品。资产托管在 UOB Kay Hian，以客户名义设立独立信托账户。

![合作基金管理人](https://cdn.growbeansprout.com/strapi-uploads/Endowus_Partners_21_Jan_2025_b39126c31d.jpg)

你可以选择平台配置的组合，也可通过 Fund Smart 自选基金。开户后支持 eGIRO 按周、双周或月定投，无锁定期；赎回通常需 2–5 个工作日。

## 总费用要分两层看

Endowus 收平台服务费（Access Fee），基金自身也有管理费。后者通常已反映在净值中，不能只看平台费率。

| 费用 | 规则 |
| --- | --- |
| 开户、账户维护 | 免费 |
| 申购、赎回、转换 | 无销售佣金和交易费 |
| 平台服务费 | 年费率 0.15%–0.60%，涵盖咨询、托管和再平衡等 |
| 基金管理费 | 通常约 0.05%–1%/年，已计入净值 |
| 销售回扣 | 100% 返还客户，降低基金层面的实际成本 |

以下按 [官方定价页](https://endowus.com/pricing) 整理，平台费另加 9% GST。

### 现金投资

多基金组合的费率随现金资产规模变化：

| 投资金额 | 年费率 |
| --- | --- |
| 不超过 S$200,000 | 0.60% |
| S$200,001–S$1,000,000 | 0.50% |
| S$1,000,001–S$5,000,000 | 0.35% |
| S$5,000,001 起 | 0.25% |

Fund Smart 只选一只基金时，S$5,000,000 以内为 0.30%，更高金额为 0.25%。Cash Smart 现金管理组合统一收 0.15%。

例如 S$10,000 的现金多基金组合，全年平台费约 S$60，加 GST 后约 S$65.40；基金管理费另算。

### CPF 和 SRS 投资

| 组合 | 年平台费率 |
| --- | --- |
| Core、Flagship、ESG、Satellite 等组合 | 0.40% |
| Fund Smart 多基金组合 | 0.40% |
| Fund Smart 单基金 | 0.30% |

CPF、SRS 与现金资产分开计费，不合并计算资产阶梯。CPF 交易还可能产生 DBS、UOB 或 OCBC 等代理银行的费用，每笔约 S$2–S$2.50。Income 和 Cash Smart 不适用于 CPF/SRS，具体基金可用哪类资金购买，也要逐项确认。

## 产品怎么选？

| 产品 | 用途 |
| --- | --- |
| Flagship / Core | 3 年以上的长期投资，以全球股票和债券分散配置 |
| Income | 偏固定收益和分红策略 |
| Cash Smart | 短期现金管理，分 Secure、Enhanced、Ultra 三档 |
| Fund Smart | 自选基金，可买一只或自行组合 |
| ESG | 可持续投资主题 |
| Satellite | 在已有核心组合之外增加区域或主题配置 |

Cash Smart 虽然用于现金管理，仍是投资产品，赎回也需要时间。需要当天动用的钱，不宜全部放入。

## 哪些情况值得考虑？

有 CPF OA 或 SRS 资金、准备长期持有，又希望由平台维护组合，可以优先了解 Endowus。它的便利主要在于资金来源、基金选择和组合管理集中在一个账户。

小额现金投资则要比较费用：S$200,000 以下多基金组合的平台年费率为 0.60%。如果只买一只低成本指数基金、愿意自己管理，也可比较 POEMS 等券商的费用。

与 StashAway、Syfe 等平台相比，主要差异是：

| 项目 | Endowus | StashAway / Syfe 等 |
| --- | --- | --- |
| CPF OA | 支持 | 一般不支持 |
| 底层资产 | 以互惠基金为主 | 多以 ETF 为主 |
| 自选基金 | Fund Smart 可选 | 选择较有限 |
| 现金起投 | S$1,000 | 部分产品门槛更低或无门槛 |
| 平台费率 | 0.15%–0.60% | 约 0.2%–0.65%，按产品核对 |

Endowus 后续追加投资每次至少 S$100，目前不服务美国税务居民，包括美国公民和绿卡持有者。CPF、SRS 产品还受各自账户规则限制，开户前需确认资格。
