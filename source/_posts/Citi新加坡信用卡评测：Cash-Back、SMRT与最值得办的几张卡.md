选 Citi 信用卡，先看每月消费能否达标，再看高返类别和上限。SMRT 偏网购与通勤，Cash Back 偏加油、打车和餐饮，Cash Back+ 规则较简单。**5% 或 8% 是指定条件下的回馈，不是整张卡的平均返现率。**

本文按 2026 年 7 月的产品和活动信息整理，迎新礼及限时优惠保留原截止日期，申请前需查看新条款。

## 先选哪一类？

| 消费习惯 | 可先比较 |
| --- | --- |
| 网购、超市、公交地铁较多 | Citi SMRT：指定类别约 5%，账单月消费需满 S$500 |
| 加油、打车、餐饮较多 | Citi Cash Back：加油及私人通勤 8%，餐饮及超市 6%，账单月需满 S$800 |
| 消费分散，不想跟踪类别 | Citi Cash Back+：合资格消费约 1.6%，无最低消费及返现上限 |
| 希望累积机票里程 | Citi PremierMiles：本地 1.2 mpd、外币 2.2 mpd |
| 已熟悉积分规则、网购较多 | Citi Rewards：部分场景可达约 4 mpd，需核对类别及上限 |

mpd 指每消费 S$1 获得的里程数。Citi 还有 M1、Prestige 等卡，可从 [信用卡总览](https://www.citibank.com.sg/credit-cards) 查看。

## SMRT：适合网购和通勤，按年封顶

[SMRT 官方页面](https://www.citibank.com.sg/credit-cards/cashback/smrt-credit-card)

| 项目 | 规则 |
| --- | --- |
| 高返类别 | 杂货、合资格线上消费、出租车 / 网约车、SimplyGo 公交地铁 |
| 门槛 | 账单月零售消费至少 S$500 |
| 达标回馈 | 指定类别约 5% SMRT$ |
| 未达标及其他消费 | 约 0.3% |
| 上限 | 无月上限，会员年高返累计约 SMRT$600 |
| 兑换 | 通常可按 1:1 换账单返现或购物券，需达到兑换门槛 |
| 年费 | S$196.20，含 GST；新户常见首两年豁免 |

年上限比月上限更适合偶尔的大额网购。例如买家电，只要交易合资格、账单月达标且年度额度尚有余额，就可能获得整笔 5% 回馈。

大额支付前，重点确认以下限制：

- **网上付款不一定有 5%。** 手机钱包类和旅行相关交易可能被排除，机票、酒店尤其要核对 [奖励排除及 MCC 列表](https://www.citibank.com.sg/rwdexcl/)。
- **Grab 行程用卡直接付。** 通过 GrabPay 钱包充值或中转，通常拿不到相同加成。
- **公交地铁用 SimplyGo。** 新卡不再依赖旧 EZ-Link 储值逻辑。
- **MYR 5% 属于限时活动。** 原活动截止日为 2026 年 8 月 31 日，之后看最新规则。
- **SMRT$ 需兑换。** 常见最低从 SMRT$10 起，在 App 或按指定短信流程办理。

## Cash Back：加油、打车和餐饮回馈较高

[Cash Back 官方页面](https://www1.citibank.com.sg/credit-cards/cashback/citi-cash-back-card)

账单月零售消费满 S$800 后：

| 类别 | 返现 |
| --- | --- |
| 汽油，MCC 5541 / 5542 | 8% |
| 私人通勤，MCC 4121，如 Grab、Gojek、Comfort、Tada | 8% |
| 餐饮 | 6% |
| 超市杂货，MCC 5411 | 6% |
| 其他零售 | 0.2% |

未满 S$800 时，消费回馈约 0.2%。**所有类别合计每月最多返 S$80**，因此支出越多，整卡平均返现不一定越高。

返现不过期，常见规则是累积满 S$50 后，以 S$10 的整数倍自动抵扣账单。年费 S$196.20，新户通常首年豁免。Caltex、Esso、Shell 等合作折扣另按活动计算，不应把油站折扣与卡返现混成一个固定比例。

## Cash Back+：消费分散时较好管理

[Cash Back+ 官方页面](https://www.citibank.com.sg/credit-cards/cashback/cashback-plus-card/)

合资格零售消费约返 1.6%，无最低消费和返现上限，在 App 或按短信流程兑换。年费约 S$196.20，新户常见首年豁免。

Citi Plus 客户若同时是 Citi Interest Booster Account 主户，并满足当月要求，可另得 0.4% Bonus；常见月上限约 S$8，需按账户条款确认。

这张卡适合支付高返卡不覆盖的杂项，但账单代付、部分缴费等仍可能没有奖励。其他银行也有约 1.7%–2% 的固定返现产品，可一起比较，别只为同一家银行而选卡。

官网曾有前两个月最高约 8% 的迎新返现，属于有消费要求和上限的活动，不是长期费率。

## PremierMiles 和 Rewards：想换机票时再看

| PremierMiles 项目 | 规则 |
| --- | --- |
| 本地消费 | 约 1.2 Citi Miles / S$1 |
| 外币消费 | 约 2.2 Citi Miles / S$1 |
| Citi Miles 有效期 | 不过期 |
| 外币交易费 | 约 3.25% |
| 年费 | 约 S$196.20，首年常豁免；续年福利按当期条款 |
| 邀请迎新 | 原活动最高约 30,000 bonus Citi Miles，需分档达标 |

外币消费虽有较高里程率，也要扣除 3.25% 费用来判断是否划算。Citi PayAll 可把部分账单支付转为里程，但有手续费，应按自己的兑换价值计算。

Citi Rewards 的线上、百货等合资格消费有积分加成，部分用户会配合 Amaze 使用，约可达 4 mpd。具体卡片、交易类别和规则可能调整，不能默认所有 Amaze 消费都适用。

不换机票的人，通常更容易用返现卡算清收益。只想减少海外费用，也可比较 [Trust Card](/2026/06/25/Trust-Card评测：新加坡最省心的信用卡推荐/) 或 [Wise](/2026/07/04/Wise评测：多币种账户与Interest收益账户推荐/)。

## 要不要同时办两张？

先确认原有支出能分别达到门槛，再考虑组合：

| 组合 | 分工 |
| --- | --- |
| SMRT + Cash Back | 合资格网购、通勤用 SMRT；加油、餐饮用 Cash Back |
| SMRT + PremierMiles | 本地合资格消费用 SMRT；外币或旅行消费按净收益选择 PremierMiles |
| Cash Back+ + 一张高返卡 | 指定类别用高返卡，其余合资格消费用 Cash Back+ |

两张卡会分散消费。原本每月只花 S$800，却要同时达到 S$500 和 S$800 的门槛，可能两张都不划算。不要为达标新增支出。

## 申请条件和迎新渠道

一般要求 21 岁以上，公民、PR 年收入约 S$30,000，外籍人士约 S$42,000。可用 Singpass 预填资料；外籍申请人通常还需工作准证、护照和住址证明等。

迎新活动通常针对新 Citi 主卡客户。过去 12 个月内注销过主卡的人可能不符合资格；批卡后也需在规定时间刷够金额，原活动常见要求为前两个月 S$800，具体按所选卡种的 PDF 条款确认。

申请前同时打开三处页面：

- [Citi 官方邀请活动](https://www.citibank.com.sg/credit-cards/landing-page/referral-program/referrer.html)
- [SingSaver Citi 优惠](https://www.singsaver.com.sg/credit-card/citibank)
- [MoneySmart Citi 优惠](https://www.moneysmart.sg/credit-cards/citibank)

官方邀请码与平台礼包通常要选一个渠道，能否叠加按活动条款确认。更多流程见 [SingSaver 与 MoneySmart 指南](/2026/06/29/SingSaver-vs-MoneySmart：新加坡信用卡比价网站怎么选/)。
