## 发生了什么：Cashback 卡还在，只是换了名字

[Trust Bank](https://trustbank.sg/) 是渣打 + FairPrice Group 的 MAS 持牌数字银行。2024 年推出的 Cashback 卡，卖点一直是：**零年费、零外汇费、App 里看返现进度**。我之前写过总览：[Trust Card 评测](/2026/06/25/Trust-Card评测：新加坡最省心的信用卡推荐/)。

2026 年 8 月 13 日，这张卡正式改名为 **Trust Freedom Credit Card**。产品条款也写明：*previously known as Cashback card*。已持有 Cashback 卡的人不用重办——下个「会员季度」起，可以在 App 里切换回馈模式。Trust 信用卡线现在就是两张：

| | **Freedom**（原 Cashback） | **Link / NTUC Link** |
| --- | --- | --- |
| 回馈 | 现金 或 美股碎股 | LinkPoints |
| 强项 | 分散消费、出国、想试投资 | FairPrice 系高回馈 |
| 年费 / 外汇费 | 都是 **$0** | 都是 **$0** |
| 能否同持 | 可以，一张账单一起还，额度共用 | 可以 |

[Fintech News SG](https://fintechnews.sg/135750/digital-banking-news-singapore/trust-freedom-card/) 的报道口径是：新加坡**第一张**把日常刷卡回馈直接变成美股 / ETF 碎股的信用卡。Trust 还说后续会加 **Miles 里程模式**（MoneySmart 写预计两三个月内，细则未公布）。

## 三种模式怎么选？

每季选一种，**当季中途不能换**；App 里随时改「下一季」的选择，不收费、不罚。季度按你办卡时锁定的会员季走，不是自然年的 1–3 月，签了就不能改起始月。

路径：Trust App → **Rewards** → **Switch quarterly reward**。

### 1. Stockback：促销期最能打，尤其是出国

这是改名真正的新东西。

| 项目 | 到 2026-12-31 | 2027-01-01 起 |
| --- | --- | --- |
| 本地合格消费 | **3%** | **2%** |
| 外币 / 境外处理的消费 | **3%** | **0.5%** |
| 季度上限 | Stockback 价值 **S$500**（约刷 **S$16,667**） | 同样封顶 S$500 |
| 起投门槛 | 累计满 **S$10** 才买入碎股 | 同上 |

怎么入账：

1. 先在 App 里选定一只美股或美股 ETF（约 **50** 只，含 NVDA、AAPL、MSFT、AMZN、VOO、QQQ 等）
2. 合格消费按比例累积 Stockback 价值
3. 满 **S$10** 后自动下单（非交易日顺延），大约 **5 个工作日**进你的 Trust Stocks 账户（合作券商为 Saxo）
4. 卖出碎股官方宣传 **$0 佣金**；下单失败则可能改以现金形式进股票账户

换一只标的随时可以，一般下一笔开市生效。销卡时，**还没凑满 S$10 的零头会作废**。

**粗算**：促销期刷满上限，一季最多约 **S$500** 的股票；要凑出第一笔 S$10，大约要刷 **S$333**。外币场景里，传统卡往往先扣 **3.25%–3.5%** 外汇费，Freedom 是 **0 外汇费 + 3% 回馈**——这也是 [SuiteSmile](https://suitesmile.com/blog/2026/08/13/trust-cashback-card-rebranded-trust-freedom-card-stockback/) 和 r/singaporefi 里不少人觉得「年底前出国可以先切 Stockback」的原因。

但股票会涨会跌。有人打算入账就卖掉、近似当 3% 现金；也有人提醒换汇进美股、以后卖出可能还有点差。**别把 3% 当成无风险返现。**

2027 年起外币掉到 0.5%，本地 2%，竞争力会明显弱一截。把它当成**年底前的窗口**，比当成长期神卡更稳。

### 2. 无限返现：懒人默认档

| | 本地 | 外币 |
| --- | --- | --- |
| 返现 | **1.5%** | **0.5%** |
| 门槛 / 上限 | 无 | 无 |

这是改名后新加的现金档。以前 Cashback 卡本地只有 **1%** 无上限，评测里常被嫌「本地不够打」；1.5% 之后，才勉强能跟 [MariBank 信用卡](https://suitesmile.com/blog/2026/08/08/trust-cashback-card-review/)、[Citi Cash Back+](/2026/07/12/Citi新加坡信用卡评测：Cash-Back、SMRT与最值得办的几张卡/) 放在同一桌比较。

要注意：

- 外币在现金模式下仍是 **0.5%**，不是 1.5%
- [Mari 信用卡](/2026/07/25/MariBank评测：2.88利息促销与Mari-Savings新户怎么开/) 目前外币也可到 **1.5%**，但每月大约只覆盖 **S$1,500** 消费，且是促销到 **2026-12-31**
- 纯拼本地无脑返现，UOB Absolute（约 1.7%）、Citi Cash Back+ / OCBC Infinity（约 1.6%）仍然略高

适合：**不想算类别、不想碰股票、本地日常为主**的人。出国大额，促销期更该切 Stockback，而不是停在这一档。

### 3. Bonus 返现：海报 15%，真实有效利率低得多

规则基本沿用旧 Cashback 卡：

- 本地基础 **1%**，外币 **0.5%**
- 另选 **1 个**类别拿加成：餐饮、购物、旅行、健康、出行、娱乐（按商户 MCC，Trust 不决定一家店的 MCC）
- 必须在一个季度的 **三个月都达标**，才按该档结算 Bonus

| 每月合格消费（连续 3 个月） | 自选类别加成 | 季度 Bonus 上限 |
| --- | --- | --- |
| **S$500** | **5%** | **S$30** |
| **S$2,000** | **15%** | **S$250** |

批卡后的**第一个日历月**，最低消费门槛豁免；之后仍要靠剩下两个月把整季档位撑住。基础返现在交易入账后就能看到；Bonus 要等季末确认三个月都达标，下一季第一天左右入账。

**为什么不能按 15% 规划？** 15% 只作用在自选类别，而且季上限 S$250，相当于这类消费大约只认到每月 **S$555**。其余那笔为了达标而刷的 S$1,445，只拿 1% / 0.5%。SuiteSmile 按「每月刷满 2,000、自选类别刚好顶满」估算，整卡有效返现大约 **5.17%**，不是 15%。MoneySmart 的分项例子也落在 **约 4.6%**。

结论：除非你**本来**每月就有两千级账单，且其中一个类别很集中（例如餐饮或购物），否则无限返现或 Stockback 更省心。r/singaporefi 里也有老持卡人直接说：1k 档被砍掉之后，15% 那条「从一开始就没必要」。

## 和其他卡怎么比？

| 场景 | Freedom | 更常被拿来比的卡 |
| --- | --- | --- |
| 年底前出国 / 外币 | **0 外汇费 + 3% Stockback**（季帽 S$500） | Mari 信用卡：0 外汇费 + 1.5% 现金，月帽约 S$1,500 |
| 本地无脑刷 | 无限返现 **1.5%** | Citi Cash Back+ / OCBC Infinity 约 **1.6%**，UOB Absolute 约 **1.7%** |
| 指定类别高返 | 单类别 5% / 15%，条件重 | [Citi SMRT](/2026/07/12/Citi新加坡信用卡评测：Cash-Back、SMRT与最值得办的几张卡/) 多类别 5%、按年封顶，通常更好刷 |
| FairPrice 买菜 | 不是它的主场 | [Trust Link](/2026/06/25/Trust-Card评测：新加坡最省心的信用卡推荐/) + [NTUC 会员](/2026/06/23/新加坡NTUC工会会员值不值得办/) |
| 碎股回馈 | 信用卡里目前几乎独一份 | Tiger BOSS 借记卡约 **1%** 碎股，还有一点海外支付费 |

MoneySmart 给这张卡大约 **3.6 / 5**：喜欢「一张卡按季度改策略」的人会加分；同一季只能选一种模式，又拼不过「一张高返 + 一张无脑」的双卡组合。这个判断我认同。

## 费用、门槛、不能算回馈的消费

| 项目 | 现行规则（2026 年 8 月） |
| --- | --- |
| 年费 | **$0** |
| 外汇费 | **$0**（按 Visa 汇率，Trust 不加价） |
| 卖出 Stockback 碎股佣金 | **$0**（官方宣传） |
| 补卡 | 现为 **$0**（原约 S$50+GST，暂免） |
| 预借现金 | 超过 **S$5** 收 **8%**（这点和早期「取现全免」的印象不同） |
| 滞纳金 | **S$100**；账单里若含分期 / Instant Loan 等则为 **S$200** |
| 利息 | 2026-07-01 起个性化 **18.9%–29.9%** p.a.，约每 6 个月检视 |
| 附属卡 | Freedom **暂不提供**（Link 卡另说） |
| 收入门槛 | 公民 / PR：21–55 岁 **S$30,000**，55 岁以上 **S$15,000**；外籍工作准证通常 **S$60,000** |

不算回馈的常见项（完整列表见 [产品条款](https://trustbank.sg/legal/trust-freedom-credit-card-product-terms/)）：预借现金、AXS / SAM / ATM、保费、Instant Loan、Balance Transfer、分期月供、给钱包 / 账户充值、水电房租、学费、政府缴费、赌博等。单笔合格消费须超过 **S$1** 才计回馈。

另外，2026 年 7 月起，用这张卡**从储蓄账户做海外 ATM 取现**已经不再是「免费提款神器」——SuiteSmile 专门写过这次削弱。出国刷卡消费仍是 0 外汇费；把 ATM 当钱包，请先看 App 里是否还开着海外取现、以及当地银行会不会另收费。

## 需要注意的坑

| 坑 | 影响 |
| --- | --- |
| **3% Stockback 有到期日和季帽** | 2027 年起外币只剩 0.5%；一季最多 S$500 |
| **股票不是现金** | 涨跌、换汇点差、凑不满 S$10 就销卡会作废 |
| **海报 15% 很难等于真实回报** | 有效利率多半在 5% 上下，还要连续三个月刷满 |
| **现金模式内外币只有 0.5%** | 出国若停在无限返现 / Bonus，会亏促销窗口 |
| **同一季只能一种模式** | 不能「买菜 15%、出国 3%」同时拿 |
| **邀请码必须当时填** | 事后补填通常无效 |

## 适合谁办？

**建议办 / 建议切过来：**

- 还没有零外汇费的卡，年底前有旅行或外币账单
- 想用碎股当「被迫定投」，能接受标的涨跌
- 本地消费分散，只想要一张 1.5%、不用算门槛的卡
- 已经有 Link 卡，想再补一张「非 FairPrice」日常卡（两张一起还）

**可以观望：**

- 几乎只在 FairPrice 系消费 → 办 Link，不是 Freedom
- 已经有 1.6%–1.7% 无脑卡，又没有出国计划
- 冲着「稳稳 15%」或「稳稳 3% 到永远」——这两句都不成立
- 收入或准证达不到门槛

## 最后说两句

Freedom 不是「改个名就变神卡」。它比较像一张**季度可换挡**的工具卡：

1. **2026 年底前有外币账单** → 优先 Stockback，把 3% + 0 外汇费用掉
